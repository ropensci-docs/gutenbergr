# Package index

## Core Functions

- [`gutenberg_download()`](https://docs.ropensci.org/gutenbergr/reference/gutenberg_download.md)
  : Download one or more works using a Project Gutenberg ID
- [`gutenberg_works()`](https://docs.ropensci.org/gutenbergr/reference/gutenberg_works.md)
  : Get a filtered table of Gutenberg work metadata
- [`gutenberg_strip()`](https://docs.ropensci.org/gutenbergr/reference/gutenberg_strip.md)
  : Strip header and footer content from a Project Gutenberg book
- [`gutenberg_add_sections()`](https://docs.ropensci.org/gutenbergr/reference/gutenberg_add_sections.md)
  : Add a section column to a Gutenberg tibble

## Cache Functions

- [`gutenberg_cache_clear_all()`](https://docs.ropensci.org/gutenbergr/reference/gutenberg_cache_clear_all.md)
  : Clear all files from the Gutenberg cache
- [`gutenberg_cache_dir()`](https://docs.ropensci.org/gutenbergr/reference/gutenberg_cache_dir.md)
  : Get the active cache directory path
- [`gutenberg_cache_list()`](https://docs.ropensci.org/gutenbergr/reference/gutenberg_cache_list.md)
  : List files in the Gutenberg cache
- [`gutenberg_cache_remove_ids()`](https://docs.ropensci.org/gutenbergr/reference/gutenberg_cache_remove_ids.md)
  : Delete specific files from the cache
- [`gutenberg_cache_set()`](https://docs.ropensci.org/gutenbergr/reference/gutenberg_cache_set.md)
  : Set the Gutenberg cache type

## Mirror Functions

- [`gutenberg_get_all_mirrors()`](https://docs.ropensci.org/gutenbergr/reference/gutenberg_get_all_mirrors.md)
  : Get all mirror data from Project Gutenberg
- [`gutenberg_get_mirror()`](https://docs.ropensci.org/gutenbergr/reference/gutenberg_get_mirror.md)
  : Get the recommended mirror for Gutenberg files

## Data

- [`gutenberg_authors`](https://docs.ropensci.org/gutenbergr/reference/gutenberg_authors.md)
  : Metadata about Project Gutenberg authors
- [`gutenberg_languages`](https://docs.ropensci.org/gutenbergr/reference/gutenberg_languages.md)
  : Metadata about Project Gutenberg languages
- [`gutenberg_metadata`](https://docs.ropensci.org/gutenbergr/reference/gutenberg_metadata.md)
  : Gutenberg metadata about each work
- [`gutenberg_subjects`](https://docs.ropensci.org/gutenbergr/reference/gutenberg_subjects.md)
  : Gutenberg metadata about the subject of each work
- [`sample_books`](https://docs.ropensci.org/gutenbergr/reference/sample_books.md)
  : Sample Book Downloads
